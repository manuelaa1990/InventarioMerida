Margen de ganancia sobre el costo convertido con el factor Binance/BCV.

Cómo se calcula el precio

factor = tasa_usdt / tasa_bcv
precio_sin_iva = costo × factor × (1 + margen/100)
precio_usd = precio_sin_iva × (1 + iva/100)
precio_bs = precio_usd × tasa_bcv

Buenas prácticas

· Las tasas BCV y USDT se actualizan solas; puedes forzarlas con Actualizar tasas ahora.

· El margen por producto es opcional: si lo dejas vacío se usa el global.

· Las ventas descuentan stock de forma atómica; no se puede vender más de lo disponible.

· El enlace público (consulta.html) nunca muestra costos ni márgenes.
